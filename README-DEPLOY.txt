RightMove — установка и запуск веб-приложения с Halpe-26

Что нужно
Windows x64, веб-камера, современный браузер и Python 3.11 или 3.12 x64.
При установке Python включите Add Python to PATH.
Скачать Python можно по адресу https://www.python.org/downloads/windows/
Установка зависимостей скачивает пакеты из PyPI и репозитория PyTorch.
После установки веб-приложение и модель запускаются локально.

Первый запуск
1. Полностью распакуйте архив в обычную папку, например C:\RightMove.
2. Дважды щёлкните Install-Web.bat и дождитесь сообщения Installation complete.
   Скрипт создаёт окружение .venv рядом с приложением и ставит CPU-версию PyTorch.
   Устанавливать Docker, WSL или CVAT для запуска RightMove не требуется.
3. Дважды щёлкните Start-Web-Halpe26.bat. Он загружает входящие в архив
   веса Halpe-26 и открывает страницу в браузере.
4. Если браузер не открылся автоматически, откройте http://127.0.0.1:8765/
5. Нажмите «Начать», разрешите доступ к камере, встаньте боком в полный рост
   и дождитесь конца калибровки. После упражнения нажмите «Завершить» для отчёта.

При последующих запусках достаточно Start-Web-Halpe26.bat.
Если окружения .venv ещё нет, этот же скрипт запустит установку.
Окно консоли должно оставаться открытым. Для остановки сервера нажмите Ctrl+C.

Если что-то не запускается
• Python не найден. Откройте CMD и проверьте py -3.11 --version или python --version.
• Порт 8765 занят. Запустите из CMD в папке приложения:
  Start-Web-Halpe26.bat --port 8766
  Страница в этом случае будет доступна по адресу http://127.0.0.1:8766/
• Камера недоступна. Разрешите доступ в браузере и закройте другие приложения,
  которые используют камеру.
• Установка пакетов прервалась. Проверьте доступ к pypi.org и
  download.pytorch.org и запустите Install-Web.bat ещё раз.

Производительность
Установка по умолчанию работает на CPU и подходит для ПК без NVIDIA.
Скорость зависит от процессора. Если на другом ПК уже есть рабочее Python-
окружение с CUDA-версией PyTorch и зависимостями RightMove, можно открыть
CMD в папке приложения, активировать это окружение и выполнить:
  python web_app.py --model data/training_runs/halpe26_v1/weights/best.pt

Что находится в архиве
Сервер и модули счётчика и оценки, папка web с интерфейсом, скрипты установки
и запуска и готовые веса Halpe-26 в data\training_runs\halpe26_v1\weights\best.pt.
