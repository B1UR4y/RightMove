# RightMove — счётчик приседаний

Учебное приложение на Python считает приседания по видео с одной камеры. Модель YOLOv8n-pose находит ключевые точки тела. По их движению приложение определяет фазы приседа и оценивает четыре аспекта техники: глубину, наклон корпуса, опережающий подъём таза и выпрямление в верхней точке. Результат каждой попытки появляется в окне с видео. Пороги оценки подобраны по записям одного человека.

## Установка и запуск в Windows

1. Установите Python 3.10 или новее. При установке отметьте **Add python.exe to PATH**.
2. Клонируйте репозиторий или скачайте и распакуйте ZIP. Откройте папку проекта и дважды щёлкните **Установка.bat**. Интернет понадобится для установки зависимостей и загрузки весов модели при первом запуске. Приложение может работать на процессоре.
3. Подключите веб-камеру и откройте **Запуск в окне.bat**. Для полноэкранного режима используйте **Запуск.bat**.
4. Встаньте боком к камере так, чтобы в кадре были видны плечо, бедро, колено и лодыжка. Постойте спокойно 2–3 секунды до завершения калибровки, затем начните приседать. Клавиша **C** повторяет калибровку, **Esc** закрывает приложение.

Для обработки готовой записи выполните команду из папки проекта, указав путь к своему видео:

```powershell
python camera_demo.py "C:\Videos\squats.mp4" --window
```

Для проверки с веб-камерой на локально обученных весах Halpe-26:

```powershell
python camera_demo.py --window --model=data/training_runs/halpe26_v1/weights/best.pt
```

Приложение показывает дополнительные точки стоп. Для оценки техники обе модели используют одни и те же правила.

## Веб-интерфейс

Запустите `Start.bat` или выполните в CMD из папки проекта:

```cmd
python web_app.py
```

Разрешите браузеру доступ к камере. Нажмите **Начать**, встаньте боком в полный рост и дождитесь калибровки.
Полоса показывает ход калибровки. После неё видны статусы четырёх правил для последней попытки.
Кнопка **Калибровать** повторяет калибровку и сохраняет результаты подхода.
Кнопка **Завершить** открывает отчёт с баллами и замечаниями по повторениям и общей оценкой подхода.
Кадры обрабатываются на этом компьютере. Сервер открывает страницу на [127.0.0.1:8765](http://127.0.0.1:8765/).
После обновления кода перезапустите сервер из папки проекта и заново откройте страницу.

Для запуска с локальными весами Halpe-26:

```cmd
python web_app.py --model data/training_runs/halpe26_v1/weights/best.pt
```

## Проверка

```powershell
python -m unittest discover -s tests
```

Синтетические тесты работают без камеры и видеозаписей. Для регрессионной проверки счётчика нужны локальные файлы точек в `data/keypoints/` или `data/penn/`. При их отсутствии эта проверка пропускается.
